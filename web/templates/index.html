GEMINI API KEY

1 Get your free key at aistudio.google.com/app/apikey (1500 req/day gratis)
2 Windows: set GEMINI_API_KEY=AIza...
Mac: add export GEMINI_API_KEY=AIza... to your ~/.zshrc
3 Restart the terminal and run python web/app.py again

YOUTUBE API SETUP

1 Go to console.cloud.google.com → create a project
2 Enable YouTube Data API v3
3 Create OAuth2 credentials (Desktop app) → download as client_secret.json
4 Place client_secret.json in the config/ folder of this project
5 Click the button below to authorize YouTube access:

✓ Browser opened — approve access on Google, then come back here.
The app detects the authorization automatically, no code needed.

! El navegador se abrirá automáticamente cuando pulses el botón. Google redirige el token directamente — no hay que copiar ningún código.
